# READING

Paper reading notes on computer architecture, systems, and hardware-software co-design.

## Organization

- `notes/`: One Markdown note per paper. Start from `notes/_template.md`.
- `papers/`: PDFs that may be shared or stored here. Check a paper's license and file size before committing it.

Use a descriptive filename such as `2026-author-short-title.md`. Include a DOI or paper URL in each note so the source remains easy to find.
